Todo número que aparece na tela é calculado em Python — determinístico, testado. O LLM entra só para interpretar o que já foi calculado.

Python calcula
PMC, zonas por volta, consistência, predições — 612 testes segurando cada conta
O LLM interpreta
lê o payload pronto e devolve um veredito em JSON, validado por contrato
O modelo ecoou um número diferente? O eco é sobrescrito pelo valor calculado antes de gravar no banco.

Faixa honesta no lugar de número mágico. IA com guardrails, não no volante.
